### 1.登录mysql数据库

mysql -u root -p

### 2.查看user表

切换至mysql。

use mysql;
查询user表，可以看到账户、主机、密码。

select host,user,password from user;
[![](/images/286ecea6ef21d4eff78b8ce5b4163311.md_.jpg)](https://img.950527.xyz/image/UJX)
其中主机显示的是ip地址或者主机名称，意思是限制登录的ip或者主机。“ % ” 意味着可以允许所有地址进行远程访问。也就是说，将主机地址字段设置为“ % ”或者自己的主机ip即可远程访问。

### 3.执行语句

update user set host = &#039;%&#039; where user = &#039;root&#039;;
或者

grant all privileges  on *.* to root@&#039;%&#039; identified by &quot;password&quot;;
root是mysql的用户，passowrd是你自定义的密码

最后flush 一下

flush privileges;
就可以远程访问了。
